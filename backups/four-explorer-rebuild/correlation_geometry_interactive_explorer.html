1) Geometry in an inner-product space

The fixed vector represents Xc; the rotating vector represents Yc. Their angle satisfies ρ(X,Y) = cos(θ).

2) Simulated correlated samples

A scatter of simulated standardized pairs \((X,Y)\) with the chosen correlation. When ρ is near 0, the cloud has no preferred diagonal direction. When ρ is near 1 or -1, the cloud concentrates along a line.

3) Portfolio variance as geometry

For two standardized assets with equal volatilities \(1\), the portfolio variance is σP2 = w2 + (1-w)2 + 2w(1-w)ρ. Lower correlation bends the curve downward and improves diversification.

How to use it. Move the correlation slider first. Then move the portfolio-weight slider. Watch how the angle changes, how the sample cloud rotates, and how the portfolio variance curve changes shape.
