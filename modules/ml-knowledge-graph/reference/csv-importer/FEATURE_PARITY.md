# Notion constellation parity

The v2 universal runtime preserves the latest Notion constellation behaviors while replacing Notion ZIP interpretation with reviewed CSV mappings.

| Notion constellation capability | Universal CSV implementation |
|---|---|
| Manual local import | Select or drop node and edge CSV files; no server or credentials |
| Preview before replacement | Mapping and diagnostics modal; current graph remains active until Apply |
| Restore bundled snapshot | Confirmation-protected restore of the comprehensive science sample |
| Browser persistence | Graph and import provenance stored under versioned localStorage keys |
| Graph-data export | Normalized `universal-constellation-data.json` download |
| Layouts | Forest/force, semantic, hierarchical, database clusters, radial focus |
| Navigation | Orbit, pan, zoom, node dragging, home, fit, reset, auto-rotate |
| Selection | Click, Shift-click groups, recursive source/outcome context, hash-linked node |
| Source opening | Modifier + double-click opens the node CSV URL when present |
| Adaptive labels | Zoom-aware collision-managed labels plus label-density control |
| Layers and relations | Node layers and relation toggles generated from CSV values |
| Analytics | Category/CSV-property color, degree, PageRank, reachability, numeric sizing |
| Gravity | Per-relation gravity for frequent relation types plus fallback, semantic anchor, repulsion, and collision |
| Living motion | Pause/resume physics, pulse, drag disturbance, elastic settling, restore layout |
| Persistent topology | Weight filtration, Betti curves, persistence bars, β₀/β₁/β₂, Euler characteristic |
| Area filling | Independent filtration-compatible four-edge 2-cells over 𝔽₂ |
| Visual output | PNG screenshot |
| Inspector | Original node fields, neighbors, direction-derived ancestors/descendants, PageRank, and TDA context |

CSV has no intrinsic database hierarchy. The semantic axis selected in **analytics** supplies the role that Notion database identity supplied in the original explorer. Directed edge orientation supplies source/outcome traversal semantics.
