# Migration Map — Projects 1–5 to the Atlas

The Atlas is not a directory containing five old applications. It extracts common infrastructure and migrates the mathematical essence of each project into approach modules.

## Shared functionality extracted once

The following previously appeared in more than one repository and now live in the Atlas core:

- random token generation;
- semantic token serialization;
- finite-field projection;
- M/Q/R definitions;
- subset/contributor enumeration;
- prime-field validation and matrix rank;
- polynomial evaluation;
- experiment import/export;
- HTTP server shell;
- global UI shell and parameter controls.

## Project 1 → Combinatorial lens

Migrated concepts:

- systematic direct token coordinates;
- aggregate contributor regions;
- M/Q/R capacity;
- semantic aggregation;
- cyclic permutation composition;
- region checksums;
- systematic incidence matrix;
- finite-field rank;
- exhaustive binary minimum distance for practical small `n`.

The old separate token store/server/UI is replaced by the shared experiment and shell.

## Project 2 → Spectral lens

Migrated concepts:

- finite-field polynomial coefficients;
- evaluation/CRT coordinates;
- local rank-one spectral constraints;
- projective rank target `n-1`;
- anchor semantics;
- `full` and `rank-basis` storage policies;
- physical versus abstract regions;
- simplicial/TDA summary of active hyperedges.

The Atlas does not duplicate the old web app, field implementation or token generator.

## Project 3 → Probabilistic lens

Migrated concepts:

- random region survival;
- systematic recovery probability;
- spectral recovery probability with anchor dependence;
- rank distributions;
- Wilson intervals;
- random-reveal stopping-time experiment.

The probability lens now consumes the same matrices/constraint blocks used by the deterministic lenses.

## Project 4 → Sheaf lens

Migrated concepts:

- M/Q/R region cover;
- nerve construction;
- coordinate and spectral-line style stalk dimensions;
- coboundary maps;
- cohomology dimensions;
- concrete local sections from the active finite-field token;
- overlap compatibility.

The token is no longer separately generated by the sheaf application.

## Project 5 → Information lens

Migrated concepts:

- source entropy;
- exact rank-information identity;
- conditional entropy;
- greedy marginal information gain;
- expected information under random survival;
- p-ary symmetric-channel capacity benchmark;
- p-ary Hamming rate–distortion benchmark.

## New functionality made possible only by unification

### Persistent cross-lens experiment

The user can inspect one token under all five mathematical interpretations without re-entering parameters.

### Comparison Lab

The comparison module checks bridge invariants and presents quantities side by side. In version 1 it explicitly verifies that the systematic rank seen by the combinatorial lens equals the rank used by the information-theoretic lens.

### Common experiment files

A single JSON file now describes an experiment rather than an input format for only one application.

## Deliberately not copied verbatim

Old repositories included independent HTTP shells, CSS, token generators, finite-field helpers, README boilerplate and duplicated parameter forms. Those are intentionally not migrated as separate copies.

The archived projects remain useful as reference implementations and historical checkpoints, but the Atlas is the active integrated architecture.

## Atlas 2.1 cryptographic layer

The five historical projects did not contain one shared cryptographic implementation. Atlas 2.1 adds a new cross-lens layer rather than migrating the former spectral basis-hiding experiment as the security primitive.

Shared once:

- AES-256-GCM encryption of the semantic token;
- LSSS/MSP distribution of the random encryption key;
- threshold and DNF access policies;
- Ed25519 authentication of issued shares;
- coalition authorization/reconstruction;
- leakage classification;
- survival/compromise simulation.

Lens-specific policy interpretation remains modular:

- combinatorial, probabilistic and information lenses can derive minimal rank-basis coalitions;
- spectral derives rank-`n-1` + anchor coalitions;
- sheaf derives coordinate-covering patch coalitions.

The old spectral keyed-conjugation/basis-hiding work is retained only as an educational algebraic comparison. It is no longer the Atlas confidentiality mechanism.
