CRYPTOGRAPHIC ACCESS-STRUCTURE LAB

AEAD + randomized linear secret sharing

Encrypt the current semantic token with AES-256-GCM, distribute the random encryption key across memory regions with an LSSS / monotone span program, authenticate shares with Ed25519, and measure leakage, availability and compromise risk.

The JSON is interpreted as an OR of AND clauses. Each listed set is a minimal authorized coalition and is compiled into a randomized monotone-span LSSS.

Security model: confidentiality/integrity of the token comes from AES-256-GCM; access control comes from fresh-randomness LSSS shares; Ed25519 detects modified dealer-issued shares. The legacy invertible rank-preserving transform is retained only as a comparison and is not the cryptosystem.
