Quick reference guide

Purpose. Use this explorer to see portfolio risk as a quadratic form over the long-only weight simplex.

Controls / options

ItemMeaningHow to read it
σ₁, σ₂, σ₃Asset volatilities.Higher volatility tends to raise the surface near that asset's vertex.
ρ₁₂, ρ₁₃, ρ₂₃Asset return correlations.Lower/negative correlations can create a deeper diversification valley.
w₁, w₂Current portfolio weights; w₃=1−w₁−w₂.Moves the current portfolio across the simplex.
yaw / pitchCamera orientation.Changes only the view.

Charts

ItemMeaningHow to read it
Triangular baseAll long-only portfolios satisfying w₁+w₂+w₃=1.Vertices are 100% allocations; interior points are mixtures.
Variance surfaceHeight equals σ²ₚ=wᵀΣw.Lower regions are lower-risk allocations.
Current pointSelected weights and their risk.Compare its height with the minimum region.
Approx min pointGrid-search approximation to the long-only minimum-variance portfolio.Shows where covariance diversification is strongest.

Metrics

ItemMeaningHow to read it
Current weights(w₁,w₂,w₃).Must sum to 1.
Current variancewᵀΣw.Square root gives portfolio volatility.
Approx min varianceLowest grid-searched variance.A numerical approximation, not an exact optimizer.
Argmin weightsWeights associated with the grid minimum.Use as an intuition aid, not a production optimizer.

Core mathematical identity

σ²ₚ = ΣᵢΣⱼ wᵢwⱼCov(Rᵢ,Rⱼ) = wᵀΣw.
