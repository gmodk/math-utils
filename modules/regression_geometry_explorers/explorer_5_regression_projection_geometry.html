Core identities: β̂ = <x_c, y_c> / <x_c, x_c>, ŷ_c = proj_span(x_c)(y_c), and y_c = ŷ_c + e with <x_c, e> = 0.

1) Scatter plot and fitted line

The data are generated from y = βx + σε. The fitted line is ŷ = α̂ + β̂x. The highlighted residual is the vertical gap from the selected point to the line.

2) Projection triangle in data space

In centered form, the response vector decomposes as y_c = ŷ_c + e. The horizontal vector is the projection onto span(x_c), and the residual is orthogonal to it.

3) Sum of squares decomposition

Regression with intercept gives the exact identity SST = SSR + SSE, where SST = ‖y_c‖², SSR = ‖ŷ_c‖², and SSE = ‖e‖².

4) Algebra / geometry summary

Key identity: R² = cos²(θ), where θ is the angle between x_c and y_c.

Quick reference guide

Purpose. Use this explorer to see ordinary least squares as orthogonal projection of the centered response onto span(xc).
