Quick reference guide

Purpose. Use this explorer to see principal component regression (PCR) as regression after rotating the predictor space into orthogonal variance directions and optionally discarding low-variance components.

Controls / options

ItemMeaningHow to read it
common correlation ρCreates three predictors sharing a common latent factor.Higher ρ concentrates predictor variance in PC1.
PCs kept kNumber of principal components used for regression.Smaller k reduces dimension and variance but may discard predictive signal.
noise σOutcome noise.Higher noise reduces predictability.
sample sizeTraining observations.More data stabilizes both PCA and regression.
signal mixInterpolates between signal aligned with the dominant common direction and signal aligned with a contrast/weak direction.Shows why high-variance PCs are not always the most predictive.

Charts

ItemMeaningHow to read it
Eigenvalue spectrumVariances of PC1–PC3.A steep spectrum indicates low-dimensional predictor geometry.
PC1–PC2 score plotTraining observations after PCA rotation.Axes are orthogonal by construction.
Coefficient comparisonOriginal-variable coefficients from OLS and PCR.PCR can change coefficients substantially when components are dropped.
Observed vs fittedPCR predictions.Diagonal proximity indicates fit.

Metrics

OLS test MSEPrediction error on a fresh test set using all predictors.Baseline.
PCR test MSEPrediction error using k PCs.Can improve under strong collinearity/noise, but can worsen if discarded PCs carry signal.

Core mathematical identity

PCR rotates X=X_scores Vᵀ, regresses y on the first k score columns, then maps coefficients back with β_PCR=V_k γ̂.
